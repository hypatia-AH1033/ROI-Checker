# ROI-Checker
Operational Audit and Proposal Self-Check Prompts
------------------------------------------------------------------------------------------------------------

AIにこのプロンプトを入力して、対象のファイルを添付して実行ボタンを押すだけでレポートが立ち上がります。
修正箇所や確認事項がリスト化されるので、それに沿って調整を進めてください。


⚠️ 注意：比較データのファイル集約ルール<br>
【仕様上の注意】
Copilotは "「今開いている単一のExcelファイル（別シート含む）」" の情報のみを参照・解析します。
別ファイル（過去資料や別保存の実績データ）を直接参照することはできません。<br>
他のAIを使用する場合は、そのAIの仕様を確認してください。

【事前準備の1ステップ】
ROI検証（事前予測 vs 実績データの比較）を行う際は、1つのExcelファイル内にシートを分けてデータを集約してからCopilotを実行してください。

【推奨ファイル構成（1つのExcel内に集約）】

```text
[Excelファイル名: 〇〇システム_ROI検証シート.xlsx]
+-----------------------------------------------------------------------+
|  Sheet1: 企画時データ   |  Sheet2: 運用実績データ  |  Sheet3: AI検証レポート  |
+-----------------------------------------------------------------------+
```

💡 実行手順<br>
比較データのコピー:<br>
過去の企画時データ（予測）と、今回の実績データを同じExcelファイルの「別シート」にそれぞれ貼り付ける。

プロンプトの実行:<br>
「Sheet1（企画時）とSheet2（実績）の数値を照合し、差分と異常値を抽出してSheet3に出力してください」 のように、シート名を指定してCopilotへ指示を出す。
